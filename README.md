# Stock Market Volatility Predictor - Frontend (HTML/CSS/JS)

1. Open `config.js` and set `window.API_BASE_URL` to your Render backend URL.
2. Run locally by opening `index.html` (or `python -m http.server 8000`).
3. Deploy free: Render "Static Site" (publish dir = `frontend` or `.`) or GitHub Pages.
4. Then set `CORS_ORIGINS` on the backend to your frontend URL.
